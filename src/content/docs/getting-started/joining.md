# Joining the Server

Install Vintage Story 1.22 and the same mod package set used by the server. The server address is shared with players through the private community channel; contact a moderator if you do not have it.

## Before connecting

- Make sure the client uses the server's Vintage Story 1.22 baseline.
- Install every required client-side package from the current server bundle.
- Read the [Mods inventory](/mods/) and the support-package section when resolving dependency errors.
- Keep a backup of an existing world before changing a large mod set.

## First session

Join through the multiplayer screen, allow the client to finish loading packages, and check the in-game handbook for the installed versions. Start with the [guides](/guides/) for thirst, maps, voice chat, food, farming, mining, transport, and building materials.
