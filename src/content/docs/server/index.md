# Server

The public compatibility baseline is Vintage Story **1.22**. The server's bundled package versions are authoritative even when an upstream project has released something newer.

## Mod parity

Install the same package set as the server before joining. Begin with the complete [Mods inventory](/mods/); its support section names libraries, add-ons, configuration companions, and compatibility patches that may not have their own player-facing page.

## Content source

The public site is generated from static Markdown and TypeScript metadata. The bundled package references are authoring input only and are not served or included as complete mod archives in the generated website.
