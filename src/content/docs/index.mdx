## Server vision

This server is built around a challenging survival experience. The mods described in the [guides](/guides/) and listed in the [Mods catalogue](/mods/) make progress more involved and give players reasons to rely on one another.

Share knowledge, resources, and work with the community. No one is expected to master every system alone; cooperation is part of how you will progress.
